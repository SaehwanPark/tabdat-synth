# Relationship to Synthpop

TabDat-Synth is conceptually inspired by R's `synthpop` package and the broader literature on synthetic tabular data. The shared idea is that useful synthetic data can be generated by learning structure from observed records and sampling new records from learned or configured mechanisms.

> Nowok, B., Raab, G. M., & Dibben, C. (2016). synthpop: Bespoke creation of synthetic data in R. *Journal of statistical software*, 74, 1-26.

TabDat-Synth is a cleanroom implementation. It was not built by reverse engineering `synthpop`, and it does not reuse `synthpop` source code. Its architecture, public API, configuration format, and implementation are independent.

Nonetheless we do acknowledge that Synthpop is an important reference point for users who know synthetic tabular data from the R ecosystem. Doing so helps orient those users while making the implementation boundary explicit.


## Comparison

| Dimension | TabDat-Synth | R `synthpop` |
| --- | --- | --- |
| Primary language | Python | R |
| Primary audience | Python data scientists, ML engineers, and research programmers | R users, statisticians, and survey-data analysts |
| Implementation relationship | Independent cleanroom implementation | Original external package |
| Configuration style | Explicit YAML or Python generation specs | R functions and method settings |
| Execution model | Directed acyclic graph of generation steps | Sequential variable synthesis workflow |
| Reuse model | Fitted bundle directories for later generation | R object and workflow patterns |
| Built-in evaluation | Fidelity metrics and disclosure-risk heuristics | Evaluation depends on the Synthpop workflow and R ecosystem tools |
| Privacy guarantee | Depends on configuration, methods, and review | Depends on configuration, methods, and review |

## Practical migration note

Users coming from Synthpop should expect similar high-level goals but different mechanics. In TabDat-Synth, users author a schema and DAG-oriented generation specification, then fit and sample through Python entry points.
